# Notas preparadas para v1.0.0

Estas notas acompañan al [cierre de la v1](cierre-v1.md). El tag `v1.0.0` y la
release todavía no se han creado.

Primera versión de orquestación supervisada para tareas Python acotadas:

- Desarrollo, evaluación independiente, revisión y control del flujo separados,
  con presupuestos limitados y evidencia conservada.
- Benchmark de reparación y tareas configurables de uno o varios archivos,
  con candidatos separados de los originales e incorporación humana explícita.
- Planificación de borradores con referencias del commit base de Git y
  continuaciones que conservan los materiales originales.
- Inspectores de registros, exportación JSON/CSV y demo estática sin modelo.
- Experimentos reales documentados y cobertura automática con agentes simulados;
  validación integrada de 768 métodos reutilizada para el cierre documental.

Preparar contratos y evaluadores, resolver ambigüedades y autorizar incorporaciones
sigue requiriendo intervención humana. Un borrador o dictamen favorable no aprueba
su propio desarrollo. Los casos observados no acreditan fiabilidad general ni
aislamiento para código arbitrario no confiable.

El cierre no añade funcionalidades ni implementa el refactor sugerido en la
demostración del planificador. Las ampliaciones futuras quedan fuera de esta v1;
no son requisitos para darla por cerrada.
